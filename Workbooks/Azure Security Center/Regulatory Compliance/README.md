# Regulatory Compliance

This workbook explores Microsoft Defender for Cloud regulatory compliance,
workload posture, control recommendations, and configuration evidence across
selected subscriptions. History views query a selected Log Analytics workspace
when configured. Observed results are not certification evidence.

The template is based on the
[Regulatory Compliance workbook](https://github.com/billmcilhargey/Microsoft-Defender-for-Cloud/tree/0918273dafc17f79709678884adadde2016a8667/Workbooks/Regulatory%20Compliance).
The original author is [Vanessa Bruwer](https://github.com/vanessabruwer), with
contributions from [Dr Bill Mcilhargey](https://github.com/billmcilhargey) and
[Lior Arviv](https://github.com/liorarviv). See the linked source for detailed
usage, prerequisites, and limitations.
